    Cum se folosește

    1. Încarcă un .dwg / .dxf (buton sau trage fișierul pe pagină). Verifică unitățile afișate: toate cantitățile depind de ele.
    2. Scrie cererea în cuvintele clientului (sau adaugă sugestiile din legendă) și apasă Analizează. AI-ul alege doar ce se măsoară; cifrele vin din geometrie.
    3. Verifică: click pe un element arată sursele pe plan, formula, factorii (galben = presupus) și lista entităților cu handle-uri AutoCAD; click pe o entitate o localizează.
    4. Corectează fără AI: modifică un factor, elimină o sursă (×), schimbă toleranța sau adaugă elemente din Explorare planșă → Catalogul planșei (butonul +). Salvează păstrează varianta în Istoric.
    5. Exportă în Excel (factorii rămân editabili, totalurile se recalculează) sau copiază tabelul.

    Plan

    • Rotița / ciupire = zoom, tragere = deplasare; tastatura: + − 0 și săgețile.
    • Riglă: click = punct, dublu-click = închide suprafața, Esc = șterge. Calibrează unitățile… fixează scara după o lungime cunoscută.
    • Copiază selecția pentru AutoCAD (în lista de entități) dă un cod AutoLISP care selectează exact entitățile numărate.

    Taste

    • Ctrl/⌘+Enter în cerere = Analizează · ← → pe file = schimbă fila
